## 4. Order and export

1. In the Frames panel, drag the header to the top. Then order the frames by step: canvas, Why each Post-it, Step 2, Step 3, mockups, Step 4, Step 5, logic, configuration, wedge, riskiest claim, choices, sources.
2. Export the frames: in the Frames panel, open the "⋯" menu and choose Save as PDF (or Board menu → Export → Save as PDF and pick the frames). Each frame becomes a page, in panel order.
3. The canvas is split over three frames side by side ("Business Model Canvas (1 of 3)" to "(3 of 3)", area x 3486–8982, y 9644–12757). If you want the 9 boxes on one page, export that area on its own (Export → Save as PDF or image, area option) and put it first in the PDF you hand in.

## How the frames were made

`miro4/gen4.py` writes each frame as Canvas Composer SVG from `docs/pitch/value-creation-analysis.md` (its scratchpad copy is the generator's source), and `miro4/ingest4.py` records the ids Miro returns (`ids4.json`, `links.json`). The header's board-map links come from `links.json`, so the header is always generated last. `miro5/gen5.py` (Oct 12) rebuilds the header, central business logic, configuration, wedge and riskiest-claim frames with the same builder (`gen4.B4`: Noto Sans, 90/67/33/22/20 px, the same blues, yellows and reds, middle-aligned table cells). It takes slide 9's sentences, wedge and vision and slide 7's riskiest claim as fixed strings, checks that `docs/pitch/value-creation-analysis.md` carries them word for word, and reads everything else from the VCA by heading rather than by line number. It refuses old wording (status words, "link or fax", "A practice manager will pay", "built for any physician", `[N#]` markers the Sources frames don't list) and checks that each frame fits its drag target. `miro5/ingest5.py` records the ids (`ids5.json`, `links5.json`); the header was generated last so its board map points at the new frames. Only `canvas_create_from_svg` was used. `canvas_update_from_svg` asks for approval on every call, so it can't run while nobody is watching, and the Free plan allows 100 tool calls a day.
